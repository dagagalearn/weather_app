# Weather App

## For Developers
If you are a developer trying to use the code, follow these steps:

- Click **Code**, then download the ZIP file.
- Alternatively, use the `git clone` command followed by the link to this repository.
- To run the app, use `flutter run --dart-define=apiKey=YOUR_REAL_API_KEY`.
- If you do not have an API key:
    - Go to https://openweathermap.org and sign up.
    - Go to **My API keys**, generate your own key, and run `flutter run --dart-define=apiKey=THE_KEY_YOU_GOT`.
